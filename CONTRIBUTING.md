# CONTRIBUTING

Правила аккаунта — в `rtynbirf/repo-doctrine` (01-чеклист, 02-ветки-и-защита, 04-конвенции-агентов).

## Как вносить изменения

1. Одна логическая правка — один коммит. Сообщения коммитов — Conventional Commits (`fix:`, `docs:`, `chore:`).
2. Аддитивность: добавлять можно; удалять и переписывать — нельзя (доктрина, раздел 02).
3. Артефакт самодостаточен: правки текста — не руками в артефакте, а через сборку в `build/`; после любых изменений — пересборка `SHA256SUMS.txt` и паспорт в README.
4. Ноль внешних запросов: гарнитуры зашиты base64 woff2; внешние ссылки в `src`/`href` запрещены гейтом CI.
5. Секреты, токены и ключи не коммитить никогда; guardian-tripwire аккаунта сканирует пуш и поднимет тревогу.

## Верификация перед пушем

```bash
sha256sum -c SHA256SUMS.txt   # GNU
```
