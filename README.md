# Язык сквозь эпохи

Автономная HTML-экспозиция: семь способов мыслить язык — от логоса к телесному предсказанию.
Один файл, ноль внешних запросов. Сиблинг по жанру — `rtynbirf/web-evolution-1991-2026`.

**Артефакт:** `language-through-the-ages-v2.html` — 548532 Б, SHA256
`c30ab945346aedd674581bb9fa8befffbdcc63fcbde00b099ab81e7e100a8a84`.
Резерв — `language-through-the-ages.zip` (406346 Б, deflate -9).
Первая редакция — `language-through-the-ages-v1.html` (38529 Б, архивная, без эпистемических комментариев).

## Что внутри

- **7 эпох, 7 голосов** — каждая эпоха говорит своей гарнитурой:
  I Античность (Cardo) → II Средневековье (UnifrakturCook + EB Garamond) →
  III Раннее Новое время (EB Garamond) → IV Просвещение (Libre Baskerville) →
  V XIX век (Source Serif 4) → VI XX век (Cormorant Garamond) → VII XXI век (Inter);
- **Эпистемический комментарий** в каждой эпохе: История / Интерпретация / Шрифт —
  граница между документированным и вчитанным проведена явно;
- **«Тень эпохи»** — тёмные стороны: иерархия языков в Средневековье, норма-под-надзором
  в Просвещении, расистское присвоение компаративистики в XIX веке, «система без человека»
  у структурализма, автоматический контроль речи в XXI веке;
- **«Одна мысль — семь языков»** — финальная таблица как проверка на анахронизм;
- **Навигация и доступность:** шапка с якорями эпох, ghost-rail, прогресс-бар (rAF),
  fade-in через IntersectionObserver, back-to-top; aria-labels, `:focus-visible`,
  `prefers-reduced-motion`, fallback без IntersectionObserver, `scroll-padding-top`.

## Автономность (v2.1) и честные границы

- **Ноль внешних запросов:** 8 гарнитур (21 лицо) зашиты base64 woff2 — 368 КБ шрифтов,
  подрезка pyftsubset по точному набору символов документа (173 знака). Открыл файл — работает,
  офлайн, без сети и сервера.
- **Кириллические фолбэки** — осознанные и прокомментированные в самом артефакте:
  кириллицы нет в Cardo, UnifrakturCook, Libre Baskerville — русские тексты этих блоков
  несут EB Garamond / Source Serif 4; латиница и греческий (φύσις, νόμος, Verbum) говорят
  фирменными гарнитурами.
- Тексты эпох — реконструкция: комментарии в артефакте отделяют историю от интерпретации.
