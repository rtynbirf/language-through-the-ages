# Язык сквозь эпохи

Автономная HTML-экспозиция: семь способов мыслить язык — от логоса к телесному предсказанию.
Один файл, ноль внешних запросов. Сиблинг по жанру — `rtynbirf/web-evolution-1991-2026`.

**Артефакт:** `language-through-the-ages-v2.html` — 548532 Б, SHA256
`c30ab945346aedd674581bb9fa8befffbdcc63fcbde00b099ab81e7e100a8a84`.
Резерв — `language-through-the-ages.zip` (406346 Б, deflate -9).
Первая редакция — `language-through-the-ages-v1.html` (38529 Б, архивная, без эпистемических комментариев).

## Что внутри

- **7 эпох, 7 голосов** — каждая эпоха говорит своей гарнитурой:
  I Античность (Cardo) → II Средневековье (UnifrakturCook + EB Garamond) →
  III Раннее Новое время (EB Garamond) → IV Просвещение (Libre Baskerville) →
  V XIX век (Source Serif 4) → VI XX век (Cormorant Garamond) → VII XXI век (Inter);
- **Эпистемический комментарий** в каждой эпохе: История / Интерпретация / Шрифт —
  граница между документированным и вчитанным проведена явно;
- **«Тень эпохи»** — тёмные стороны: иерархия языков в Средневековье, норма-под-надзором
  в Просвещении, расистское присвоение компаративистики в XIX веке, «система без человека»
  у структурализма, автоматический контроль речи в XXI веке;
- **«Одна мысль — семь языков»** — финальная таблица как проверка на анахронизм;
- **Навигация и доступность:** шапка с якорями эпох, ghost-rail, прогресс-бар (rAF),
  fade-in через IntersectionObserver, back-to-top; aria-labels, `:focus-visible`,
  `prefers-reduced-motion`, fallback без IntersectionObserver, `scroll-padding-top`.

## Автономность (v2.1) и честные границы

- **Ноль внешних запросов:** 8 гарнитур (21 лицо) зашиты base64 woff2 — 368 КБ шрифтов,
  подрезка pyftsubset по точному набору символов документа (173 знака). Открыл файл — работает,
  офлайн, без сети и сервера.
- **Кириллические фолбэки** — осознанные и прокомментированные в самом артефакте:
  кириллицы нет в Cardo, UnifrakturCook, Libre Baskerville — русские тексты этих блоков
  несут EB Garamond / Source Serif 4; латиница и греческий (φύσις, νόμος, Verbum) говорят
  фирменными гарнитурами.
- Тексты эпох — реконструкция: комментарии в артефакте отделяют историю от интерпретации.

## Верификация

- `sha256sum -c SHA256SUMS.txt` — пломбы всех трёх артефактов (GNU).
- Шрифты: 21/21 woff2 открываются fontTools; 100% покрытие букв кириллицы/греческого/латиницы
  документа хотя бы одной гарнитурой; текст артефакта идентичен v2.0 (проверка нормализованной
  пробельности); внешних URL — 0; секрет-скан отдающихся байтов — 0.
- Структурная проверка при сборке: баланс тегов, 7 секций × (афоризм + тело 124–155 слов +
  словарь эпохи + комментарий), ноль случайных английских слов в русской прозе.

## Сиблинг-артефакт: «Лингвистический код · Эпохи» (v1)

`linguistic-code-epochs-v1.html` (161608 Б, SHA256
`1ab11204c3b90449dc3ef8386651a573e89dd647a0cbac3a74a2b33f1bfa6fbd`) —
инвариант хронотопа языка (канон `polimat-task174`, раздел 1, тезисы
1.5 / 1.7 / 1.23 / 1.28 / 1.31): одна мысль — конечность личного опыта и
необходимость его передачи — сказана шестью словарями эпох.
I Голос (песнь) → II Логос (λόγος) → III Знак (scriptura) → IV Кодекс
(glossa) → V Тираж (typographia) → VI Носитель (token).

- **Формат эпохи:** голос 120–200 слов → три тезиса (опыт → речь;
  внешний носитель; молчание = потеря) → «✓ знаем / ? не знаем» →
  проверка лексики. Голоса — реконструкция, граница проведена явно;
- **Словарные паспорта:** каждой эпохе заданы допустимое ядро и запрет;
  сборщик проверяет голоса на анахронизмы (токены с исключениями
  «кодекс/писание» — лексемы, а не подстроки);
- **Автономность:** ноль внешних запросов; 4 гарнитуры (Liberation Serif
  Regular/Bold/Italic + DejaVu Sans Mono) зашиты base64 woff2, подрезка
  pyftsubset по символам документа — 222/222 покрытия; вёрстка на
  min()/clamp() без @media; прогресс-бар rAF, fade-in через
  IntersectionObserver с фолбэком, prefers-reduced-motion, skip-link,
  `:focus-visible`, scroll-padding-top;
- **Сводная таблица** «одна мысль — шесть языков»: 5 шагов структуры × 6 эпох
  + вердикт (скорость копирования против цены молчания);
- **Сборка воспроизводима:** `build/epochs_data.py` + `build/build_epochs.py`
  пересобирают артефакт бит-в-бит (проверено: sha256 совпал); шрифты —
  пути системной установки, в иных средах поправить FONTS; пломбы —
  в `SHA256SUMS.txt`, резерв — `linguistic-code-epochs-v1.zip` (deflate -9).

## Сиблинг-артефакт: «Лингвистический код v18.1» (гибрид двух редакций)

`linguistic-code-v18.1-hybrid.html` (88702 Б, SHA256
`6ce8ab69f5b50f85f528ed03a16831391c2b464a63b981ec56b698a23f22976d`) —
склейка двух редакций v18 по итогам их построчной сверки: каркас и ритм —
из редакции B (лаконичной), цитатный аппарат — из редакции A
(исследовательской). Соматический вход: честный слой → инструкция телу
(указать «вчера» и «завтра») → карточка языка аймара (Núñez & Switzer,
2006) → мост с запечатыванием опыта → манифест с проверкой источников.

- **Перенесено из A:** цепочка речепроизводства Levelt (концептуализатор →
  лемма → фонологическое кодирование → артикуляция); пещера Шове
  (~36 тыс. лет — знак до письменности); критика трёхчастной модели мозга —
  Barrett (2012), Steffen et al. (2022); углублённые вопросы «что мы НЕ знаем»;
- **Оставлено от B:** раскладка цитат «источник → суть», источники,
  добавленные в B — Bender et al. (2021) «Stochastic Parrots», куук
  тхаайорре — абсолютные кардинальные направления (Boroditsky, 2011),
  Hayakawa et al. (2017); финальная честная оговорка о статусе файла;
- **Честные границы (отличие от инварианта репо):** три гарнитуры
  (Cormorant Garamond, Inter, JetBrains Mono) подгружаются с Google Fonts
  при первой загрузке — после кэширования файл работает офлайн; артефакт
  декларирует эту оговорку сам, карточкой самодостаточности. Полная
  автономность (base64-зашивка шрифтов, подрезка pyftsubset) — кандидат
  в v18.2;
- **Пломба:** `sha256sum -c SHA256SUMS.txt`; резерв —
  `linguistic-code-v18.1-hybrid.zip` (deflate -9).
